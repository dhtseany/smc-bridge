# SMC Bridge icon assets

Three independent mint faders on a teal tile, from `assets/icons/smc-bridge-v2.png`.

- `smc-bridge-original.png`: unchanged 1254 × 1254 RGBA source.
- `smc-bridge-{size}.png`: transparent PNGs at 16, 24, 32, 48, 64, 128, 256, 512, and 1024 pixels square.
- `smc-bridge.ico`: multi-resolution icon containing 16, 24, 32, 48, 64, 128, and 256 pixel images.
- `smc-bridge.gif`: static 256 × 256 GIF with transparency.

Use PNG for Linux desktop icons and general reuse. PNG and ICO preserve full alpha transparency; GIF supports only binary transparency and a limited palette, so its edges may look less smooth.
